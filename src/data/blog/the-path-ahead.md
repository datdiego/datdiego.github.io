I want to build something useful, something for me that hopefully is cool enough that people will want to build it for themselves as well.

Like building a bench using woodworking tools, I want to create the plans for this bench.

I want to build an assistant that makes my life easier. All the tools are there: Claude, ChatGPT, all LLMs in general have opened a door. To build dreams, to build magic.

So what I imagine is an assistant with the Jarvis style, but in this case it would be for me.

I see a single entity, like the nucleus of an atom, that takes on the identity of my assistant. I don't know yet what it will be called, and it will assist me in every aspect of my life.

Right now, I have a headless server that allows me to build apps. I use Notion to keep track of notes and projects across my life, work and business. I use Google and its myriad of apps to manipulate information all across.

So this nucleus will be able to create "electrons" that are either tools, agents, or information. It is just a three-dimensional representation of what any AI assistant does. But I want my custom, personalized one, and I want to show it off.

I will try to get my ideas together on this and see if I can create a single entity to become part of my life.
